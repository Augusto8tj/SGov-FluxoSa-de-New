# Ícones do Sistema (PWA)

Esta pasta foi criada para receber os ícones oficiais de instalação do SGov FluxoSaúde.

## Arquivos que você deve enviar para esta pasta:
1. `icon-192x192.png`: Ícone padrão (192x192 pixels).
2. `icon-512x512.png`: Ícone de alta resolução (512x512 pixels).
3. `maskable-icon-512x512.png`: Ícone adaptável para sistemas Android (512x512 pixels).

O sistema já está configurado para reconhecer esses nomes de arquivo automaticamente.
